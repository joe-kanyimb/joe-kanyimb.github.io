PROJET WEB · TAMADA / ÉTUDE DE CAS

Tamada : une vitrine bilingue pour une pâtisserie événementielle

Un site vitrine bilingue qui présente les créations de Tamada, ses services événementiels et un parcours de contact à Lubumbashi.

Image indisponible. Le contenu du projet reste accessible ci-dessous.

Voir le projet en ligne ↗

Contexte

Donner à Tamada une présence web claire pour présenter ses offres, ses réalisations et recueillir les demandes de devis.

Mon rôle

Conception, développement et mise en ligne du site vitrine bilingue.

Processus

Une application Next.js 16 avec React 19 et Tailwind CSS 4 organise les pages, les services, les réalisations et le formulaire de contact. Le contenu est relié à Supabase et le site est déployé sur Vercel.

Outils

Next.js 16, React 19, Tailwind CSS 4, Supabase, Vercel.

Résultat

Le site est en ligne en français et en anglais, avec des galeries de réalisations, une section contact et une navigation adaptée aux mobiles.
